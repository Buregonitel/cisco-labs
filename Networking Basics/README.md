# Networking Basics

Лабораторные работы курса **Networking Basics** (Cisco Networking Academy), выполненные в **Cisco Packet Tracer**.

Этот раздел содержит практические задания по основам компьютерных сетей: построение LAN, настройка беспроводных роутеров, DHCP, NAT, анализ трафика, работа с сетевыми сервисами и протоколами удалённого доступа.

## Сертификат

## Основные темы

- Построение и настройка локальных сетей (LAN)
- Беспроводные сети и гостевые сети
- DHCP и динамическая адресация
- NAT (Network Address Translation)
- MAC- и IP-адресация, модель OSI
- Маршрутизация и поток трафика
- DNS, HTTP, TCP
- FTP-сервис
- Удалённый доступ (Telnet vs SSH)
